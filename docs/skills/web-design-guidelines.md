# `/web-design-guidelines`

Revisa a interface que o screenshot mostra. Não redesenha o tema.

O agent `qa-visual` marca passa, falha ou "não dá para ver" em: foco, nome acessível, alvo de toque, formulário, contraste, tipo, imagem, movimento, estado vazio e a parada no carrinho.

Sem PNG, item visual não passa. Foto escura ou copy vazio da loja entra como conteúdo, não como patch de CSS. O que o tema já define em `.claude/memory/design-system.md` é a referência de cor e botão.
