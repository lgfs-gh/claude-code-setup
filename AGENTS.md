# AGENTS.md

Contrato curto para agentes neste repositório:

- Fonte canônica: `.claude/skills` e `.claude/agents`. Não duplique em outro formato.
- Instalação no tema: `node scripts/install.mjs <tema>`, conforme `docs/claude/auto-install.md`.
- Este repo não é o tema. Sem `layout/theme.liquid`, não edite Liquid aqui.
- Guardrails de tema valem quando o agente estiver no tema instalado: sem publish, sem delete, sem force-push, sem checkout, sem `.env`.
